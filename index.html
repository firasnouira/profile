About the project

CTN is a state-owned Tunisian shipping line handling ~100,000 transport units annually. Their container shipping operations were entirely managed through manual, informal processes — clients submitted requests through ad-hoc channels, agents manually selected voyages and assigned containers based on experience alone.

This platform digitizes and optimizes that entire workflow: from expedition request to real-time vessel tracking, with automated container space optimization and intelligent route planning baked in.

Core Algorithms

Two custom algorithms sit at the heart of this platform — written from scratch to solve real operational constraints, not off-the-shelf solutions.

S-DBLF Heuristic

3D Bin Packing

Implements the Simple-Deepest Bottom Left with Fill heuristic to maximise volumetric utilisation inside each container. Handles multi-leg voyages — packages are only loaded/unloaded at the correct port stop — and supports both Full Container Load (FCL) and Less-than-Container Load (LCL) shipments with weight and dimension constraints.

Space utilisation
Recursive DFS

Smart Pathfinding

A custom recursive depth-first search that discovers all time-feasible multi-port shipping routes between origin and destination. The algorithm respects voyage departure dates, transshipment window constraints, and minimum connection times — then ranks candidate paths by total transit duration so operators see the best option first.

Platform Features

Live AIS Tracking

Vessel positions pulled via the Automatic Identification System. Delay detection triggers real-time notifications and recalculates ETAs.

Expedition Lifecycle

Full state machine from pending → assigned → departed → completed, with automated plan proposals and cancellation logic.

Role-Based Access

JWT AuthGuard middleware enforces separate permissions for clients, logistics operators, and admins across all API endpoints.

Voyage Scheduling

Logistics operators manage multi-stop voyages through a calendar interface. New schedules automatically trigger pending expedition reassignment.
